I am one of the tutors of [CAB420](https://www.qut.edu.au/study/unit?unitCode=CAB420) unit. It provides a broad introduction to machine learning from linear regression to deep learning models.
Students make use of Python, JupyterLab, Git and common machine learning libraries such as `scikit-learn`, `statsmodels`, etc.
